    Cisco官网内容快速导航

    学习网络技术少不了访问Cisco的官网，如何快速导航到自己需要的内容非常重要，Cisco官网导航分下面两部分：

    1）Cisco 官网文档导航（主站 / 中文站 / 支持站）

    2）最全 Cisco Go（cisco.com/go/xxx）速查清单

    一、Cisco 官网文档导航

    1. 全球主站（英文，资料最全）

    • 首页：https://www.cisco.com/
    • 技术文档总入口：https://www.cisco.com/go/documentation
    • 产品文档 / 支持：https://www.cisco.com/c/en/us/support/index.html
    • 产品选择器（查某型号文档）：https://www.cisco.com/web/psa/products/index.html
    • 传统 UniverCD（老文档库）：http://www.cisco.com/univercd/home/home.htm

    2. 中文官网（国内用户友好）

    • 中文首页：https://www.cisco.com/c/m/zh_cn/
    • 中文技术支持：https://www.cisco.com/c/zh_cn/support/index.html
    • 中文企业网络文档：https://www.cisco.com/c/m/zh_cn/about/solutions/enterprise-networks/index.html

    3. 文档查找常用路径（3 种）

    1. 官网首页 → Support → Select a Product → 选型号 → 进 Configuration Guides / Command References
    2. 直接用 go 链接（见第二部分）直达文档 / 工具
    3. 搜索框输入：产品型号 + OS 版本 + configuration guide
