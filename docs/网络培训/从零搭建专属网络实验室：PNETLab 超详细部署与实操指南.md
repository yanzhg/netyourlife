## 二、硬件环境配置要求

PNETLab 依靠虚拟化运行网络设备，**CPU 虚拟化支持、内存大小、硬盘速度**直接决定实验稳定性，以下是分级配置参考：

### 1\. 最低配置（新手入门、小型拓扑）

- CPU：4核及以上，支持 Intel VT\-x / AMD\-V 硬件虚拟化

- 内存：主机 8GB，虚拟机分配 6GB 内存

- 硬盘：40GB 以上空闲空间，优先 SSD（机械硬盘设备启动卡顿严重）

- 虚拟化软件：VMware Workstation 12\.5\+、VirtualBox、ESXi

### 2\. 推荐配置（专业实验、多设备大型拓扑）

- CPU：6核及以上，高主频优先，多核可承载多设备并发启动

- 内存：主机 16GB 及以上，虚拟机分配 10\~12GB

- 硬盘：100GB\+ SSD，网络设备镜像占用空间较大，充足空间可避免实验中断

- 虚拟化软件：优先 VMware Workstation 16/17，兼容性、稳定性最优

> **核心前置条件**：必须在电脑 BIOS/UEFI 中开启 **Intel VT\-x 或 AMD\-V 硬件虚拟化**，未开启会导致所有网络设备启动闪退、无法运行。

## 三、PNETLab 虚拟机部署（OVA 一键导入法）

OVA 镜像导入是最简单、零报错的部署方式，无需手动安装系统，全程可视化操作。

### 步骤1：导入官方 OVA 镜像

1. 获取 PNETLab 官方 OVA 镜像文件

2. 打开 VMware Workstation，点击「文件 \- 打开」，选中下载好的 pnetlab\.ova

3. 自定义虚拟机名称与存储路径，**严禁存放C盘**，避免系统盘爆满

4. 等待导入完成，导入过程默认配置即可

### 步骤2：虚拟机核心参数配置（关键！）

导入完成后，必须修改虚拟机设置，否则设备无法正常启动：

1. **CPU 设置**：勾选「虚拟化 Intel VT\-x/EPT 或 AMD\-V/RVI（嵌套虚拟化）」，这是设备启动的核心开关

2. **内存设置**：根据硬件配置分配，新手 6GB、专业实验 10GB 以上

3. **网卡设置**：推荐 **桥接模式**，让 PNETLab 虚拟机与本机同网段，拓扑设备可正常访问外网；NAT 模式仅适合纯本地实验

### 步骤3：系统初始化与登录

1. 启动虚拟机，等待系统自动初始化，控制台会自动输出 PNETLab 本地 IP 地址

2. 控制台登录系统：默认账号 `root`，默认密码 `pnet`

3. 首次开机进入配置向导，可自定义静态 IP、DNS、主机名，新手全程回车默认即可，后续可随时修改

4. 浏览器访问：`https://虚拟机IP地址`，忽略浏览器证书不安全警告，继续访问

5. Web 端登录：离线模式账号 `admin`，密码 `pnet`，功能完全免费，满足所有个人实验需求

## 四、核心操作：设备镜像上传与适配

PNETLab 本身无内置设备镜像，需要手动上传厂商镜像，**目录结构、文件夹命名必须严格规范**，否则 Web 端无法识别设备。平台镜像分为三类，存放路径各不相同。

### 1\. 镜像分类与存放目录

- **QEMU 镜像（主流厂商设备）**
路径：`/opt/unetlab/addons/qemu/`
适配设备：华为 USG、VRP 路由器、H3C、思科 CSR、飞塔、Juniper vSRX 等
        
规范：每个设备单独建文件夹，内部镜像命名为 `hda.qcow2`

- **IOL/IOS\-L2 镜像（思科轻量化设备）**
路径：`/opt/unetlab/addons/iol/bin/`
适配设备：思科二层/三层交换机、中小型路由器，资源占用极低，适合大量组网
      

- **Dynamips 镜像（老式思科设备）**
路径：`/opt/unetlab/addons/dynamips/`
适配设备：思科 3725、7206 等老旧型号，仅用于老旧协议实验
      

### 2\. 镜像上传与权限修复（必做）

1. 使用 WinSCP、FileZilla（SCP 协议）连接 PNETLab，账号 root/pnet

2. 将对应镜像上传至上述对应目录，严格遵守命名规范

3. SSH 登录 PNETLab，执行**权限修复命令**（上传镜像后必须执行，否则设备无法启动）：
        
`/opt/unetlab/wrappers/unl_wrapper -a fixpermissions`

4. 刷新 Web 页面，左侧节点列表即可显示新增设备

### 3\. 思科 IOL 设备额外授权

思科 IOL 设备默认需要授权文件，上传镜像后，需上传 `CiscoIOUKeygen.py` 脚本，生成 `iourc` 授权文件，否则 IOL 设备启动后直接闪退。

## 五、手把手搭建首个网络实验拓扑

完成镜像部署后，即可开始自由组网，完整实验流程如下：

1. **新建实验**：Web 端点击「Add Lab」，自定义实验名称、备注，保存创建空白拓扑

2. **添加设备节点**：左侧「Nodes」菜单栏，拖拽路由器、交换机、防火墙等设备到画布

3. **链路互联**：点击设备对应端口，再点击另一台设备端口，自动完成网线连接，支持任意端口自由组网

4. **配置外网连通**：添加 Cloud0 云节点，绑定虚拟网卡，可实现拓扑内设备访问本机网络和外网，满足上网、升级、远程调试需求

5. **启动与调试**：选中设备点击「Start」启动，右键设备打开 HTML5 控制台，直接输入设备配置命令

6. **报文抓包分析**：右键拓扑链路选择「Capture」，一键开启 Wireshark 抓包，精准分析协议报文、排查组网故障

## 七、新手高频报错与解决方案

整理新手搭建过程中 90% 会遇到的问题，快速排错、避坑：

- **问题1：设备点击启动立刻停止/闪退**
解决方案：检查 VMware 是否开启嵌套虚拟化、BIOS 是否开启 VT\-x；核对镜像文件夹命名是否规范
      

- **问题2：上传镜像后Web端找不到设备**
解决方案：未执行权限修复命令，或镜像存放目录错误、文件夹命名不规范
      

- **问题3：拓扑设备无法ping通外网**
解决方案：虚拟机网卡改为桥接模式，重新配置 Cloud0 节点，检查设备网关、DNS 配置
      

- **问题4：磁盘空间不足，实验卡顿失败**
解决方案：VMware 扩展虚拟磁盘容量，进入 PNETLab 系统执行分区扩容，清理无用镜像
      

- **问题5：浏览器HTTPS访问报错**
解决方案：直接忽略证书不安全警告，继续访问，为系统自签名证书，无安全风险
