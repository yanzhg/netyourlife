# 等保测评中备份目录的安全整改

等保三级测评要求：对配置备份目录的增删改查行为要做审计，如果系统没有安装审计套件需要先安装 auditd 套件。我们这里假定备份目录是“/data/backup“。

## 步骤 1：安装 auditd

```
apt update
apt install auditd audispd-plugins -y
```

安装完成后，目录自动生成：`/etc/audit/rules.d/`

```
#启动并开机自启
systemctl enable --now auditd
systemctl status auditd
```

## 步骤 2：编写审计规则文件

创建文件：`/etc/audit/rules.d/all_device_config.rules`

```
-w /data/backup -p rwxa -k all_device_config_monitor
```

## 步骤 3：加载审计规则

```
augenrules --load
#查看已生效规则
auditctl -l
```

> 输出应当看到：`-w /data/backup -p rwxa -k all_device_config_monitor`

### 查看审计日志

审计日志文件路径：`/var/log/audit/audit.log` 检索关键字：

```
ausearch -k all_device_config_monitor
```
